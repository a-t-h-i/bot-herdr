## Build
1. **6 working animation cycles** exactly per the spec table (Thinking ⠁⠂⠄⡀⢀⠠⠐⠈, Reading ▖▘▝▗, Editing ▁▃▅▇▅▃, Testing ▱▱▱ ▰▱▱ ▰▰▱ ▰▰▰, Waiting · • ● •, Orchestrating ◜◝◞◟), via native `.frames(list, 120)` at one 120 ms tick. Glyph and verb sit in a fixed-width slot (zero layout shift); verbs rotate at most every 4 s; activity is derived from the agent's latest activity (tool kind). The avatar breathes (opacity 0.7–1.0) only while that agent works. Keep today's animations' character.
2. **Reduce motion**: a persisted toggle in Settings › General (also honour `settings().reduced_motion` when present). When on, frames freeze on their first glyph and fades become instant. Wire it through one helper in `look.js` / `working.js`, so every animation respects it.
3. **Micro-interactions** (spec table): hover steps the surface up one level (100 ms); press steps up two. Optimistic send (muted until acked). Answering a question card: the chosen option gets a check and the others fold over 150 ms. On finish: glyph → ✓ plus a 2 s soft highlight overlay (opacity, not colour). Needs-you: one amber pulse on the glyph and the Home tab badge; toast only when the window is unfocused (`herdr.window().active`). Skeletons, never spinners. Copy/save button label → "Copied"/"Saved" for 1.5 s. Destructive actions: do it, then offer Undo for 5 s; confirm dialogs only for irreversible actions. Timing tokens 100 / 150 / 250 ms from `MOTION`.
4. **Accessibility**: every interactive element gets a stable id, `role` and `accessibility_label` (100% label coverage in the audit). A polite status region via `role("status")` that announces state changes ("Dev needs you: plan question"). Targets >= 28 px on desktop. A 2 px accent focus ring that doesn't jitter (reserve the space) and isn't removed on click. State never by colour alone.
5. **Keyboard map** (100% keyboard-path coverage in the audit): global `Ctrl+Shift+P` palette, `Ctrl+1..5` destinations, `Ctrl+.` pause/resume current goal, `?` shows the map (a small overlay listing it). View-local: `J/K`, `Space` peek, `Enter` open, `Esc` close-then-back (restoring scroll and selection), `1..9` question options, `Ctrl+Enter` send. Use `keys.json` / the herdr command system where that's how globals bind; every list, panel and dialog that takes keys owns a focus handle.
6. **Audit**: make sure the audit's keyboard-path and label coverage counters reflect real `track_focus`/`on_key_down`/`role`/`accessibility_label` in the rendered spec (read how they're measured; never loosen them). Add audit detection for the animation rules if feasible (fixed-width slot, 120 ms frames, reduced-motion freeze) so QA has evidence.
7. Tests: pure tests for the frame tables, the verb rotation (<= every 4 s), reduced-motion freezing, the keymap table (no collisions), and focus/label coverage of each page's spec. Extend `test/render-resilience.test.mjs` for new components. Update, never delete or skip.
